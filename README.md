# Dukes of Beauty - Premium Luxury Salon Website

A cinematic luxury beauty salon website built with React, TypeScript, and Tailwind CSS.

## 🌟 Features

- **Cinematic Hero Section** with Ken Burns animation
- **Liquid Glass Service Categories** with Apple-inspired design
- **Complete Booking System** with custom calendar
- **WhatsApp Integration** for booking confirmations
- **Instagram Carousel** with real posts from @dukes_of_beauty.ae
- **Google Reviews** section with authentic testimonials
- **Salon Gallery** with real photos
- **111+ Services** across 7 categories
- **Mobile-First Responsive Design**

## 🚀 Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS 4
- Font Awesome

## 📦 Installation

```bash
npm install
```

## 🛠️ Development

```bash
npm run dev
```

## 🏗️ Build
