# Dukes of Beauty — Original Luxury Salon Design Restored

This repository uses the **original Dukes of Beauty black, obsidian and champagne-gold website**, including the original cinematic hero, salon introduction, category layout, Instagram and gallery sections, Google review source link, location/contact and WhatsApp appointment request flow.

## Booking and prices
- WhatsApp destination: +971 52 816 7306
- Bookings are requests sent through WhatsApp, *not* confirmed appointments or live availability.
- Full existing catalog: 111 treatments across seven categories.
- Listed menu prices were preserved with corrections previously taken from the salon's published menu.
- Variable and "from" prices do not receive invented upper estimates.
- Fake client quotes, unverified ratings and local-only fake slot reservations are not displayed.
- Reviews link directly to the salon's Google Maps listing.

## Build
```bash
npm install
npm run typecheck
npm run build
```
